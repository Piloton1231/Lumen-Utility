# Lumen Utility for Windows

Vorssaint の「1つの常駐パネルに日常ツールをまとめる」考え方を Windows 向けに再実装した、非公式・別ブランドの Windows アプリです。

元プロジェクトの商標条件に従い、Vorssaint の名前、ロゴ、アイコン、Bundle ID、署名、公式配布物を思わせるブランド表現は使用していません。暗色カード、縦長パネル、情報密度などの操作感は保ちつつ、Windows 用の外観に調整しています。

## インストール

`LumenUtility-Setup.exe` を実行してください。管理者権限を使わず、現在のユーザーの `%LOCALAPPDATA%\Programs\LumenUtility` にインストールします。

- スタートメニューへショートカットを作成
- Windows の「インストールされているアプリ」へ登録
- アンインストール時にスタートアップ設定も削除
- .NET 8 Desktop Runtime がない場合は、同梱の `install-runtime.cmd` から導入

## ポータブル版の使い方

配布 ZIP を展開し、`START.cmd` または `LumenUtility.exe` をダブルクリックしてください。通知領域に常駐します。

起動時に .NET の案内が表示された場合は、同梱の `install-runtime.cmd` を一度だけ実行してください。Microsoft .NET 8 Desktop Runtime を `winget` で導入します。

- 通知領域のアイコンを左クリック: パネルを開く / 閉じる
- 通知領域のアイコンを右クリック: 開く / 終了
- パネル右上の `×`: パネルだけを隠す（アプリは終了しません）

## v0.10.59 で使える機能

- お気に入りランチャー: EXE・ショートカットを選択して追加し、アイコンのダブルクリックで元の場所から直接起動
- お気に入り編集: 編集モードでLumen内だけの表示名変更、左右の並び替え、確認付きの削除。設定で表示ON/OFF（初期状態ON）
- 起動軽量化: 初回起動時は重いシステム情報・音量ミキサー・お気に入りアイコン取得を後回しにして、常駐開始を高速化
- 初回表示ウォームアップ: 常駐開始後のアイドル時間に非表示でUIレイアウトを先読みし、再起動後の初回クリック表示を高速化
- 今再生中プレーヤー: ONなら常にメイン画面に表示。Windows Media API から現在のメディアセッションを取得し、タイトル/アーティスト/操作ボタンを表示。設定から表示ON/OFF可能
- メディアアートワーク: Windows Media API のサムネイル/アルバム画像を取得して表示
- 長いメディア名: タイトルやアーティスト名が収まりきらない場合、自動でゆっくり横スクロール
- メディア名スクロール改善: アーティスト名が少しだけ欠ける場合もスクロール判定に入るよう調整
- メディアボタン: 再生、停止、前/次ボタンを専用PNGアイコンへ変更
- メディアボタン画像: インストール先/ポータブル先のAssetsから確実に読み込むよう修正
- ライトテーマのメディアボタン: 明るい背景で見づらくならないよう、再生/停止/前/次アイコンを反転表示
- ライトテーマの左右ボタン: 白い矢印が丸の中心からズレて見える問題を修正
- カラーテーマボタン修正: グラデーションON時もブルー/パープル/ピンク/グリーンの選択ボタンへグラデーション枠が回り込まないよう分離
- インストーラー形式変更: 誤検知されやすいIExpress/PowerShell自己解凍方式をやめ、NSIS形式の通常インストーラーへ変更
- テーマ色とグラデーション分離: グラデーションON時は背景をグラデーション色だけで作り、ブルー/パープル/ピンク/グリーンは選択枠とアクセントだけに反映。グラデーションOFF時はテーマ色で背景も塗る
- 背景グラデーション修正: グラデーションON時にテーマ色のアクセントを背景へ混ぜないようにし、オーシャンなど選択したグラデーション色だけで背景を作成
- カラーテーマプリセット: カスタムテーマカラーを名前付きで保存・呼び出し・削除可能にし、短い名前でもプリセットボタンが小さくならないよう調整
- グラデーションプリセット調整: 既存のプリセット色を少し明るめに調整
- 今再生中の安定化: 再起動直後などWindowsのメディアAPIが準備中でも、NowPlayingHelperのエラーを表示せず静かに「再生中のメディアなし」として扱う
- Windows 7 Aero スタイル: 設定のテーマ欄にトグルを追加。ONでガラス風のライトブルー/オーシャン/低不透明度へ切り替え、OFFで直前の色設定へ戻る
- Aeroガラス効果: 対応環境ではDWMのAcrylic/blur系バックドロップを要求し、非対応環境ではLumen側の半透明ガラス風表示でフォールバック
- メディア操作: 動画は5秒戻る/進む、音楽は前/次トラック、再生/停止をWindowsの現在メディアセッションへ送信
- 右下ドラッグ: `ドラッグで移動` の文字部分からもパネル移動可能
- Steamショートカット: `.url`内の`steam://`起動先と`IconFile`に対応
- ヘッダーアイコン: 左上のアイコンをPNG・JPG・BMP・GIFへ変更し、専用画面で正方形にクロップして角丸表示。設定から標準へ復元可能
- 大音量保護: ピーク75%以上が2秒続いた時に、5〜100%から指定した音量へ自動調整
- 多言語表示: 日本語、韓国語、簡体字中国語、繁体字中国語、英語
- 初回言語選択: 初回起動時にOKで確定して保存し、次回以降は自動的にスキップ
- 言語設定: Lumen設定から再起動なしで表示言語を変更

- スリープ抑止: 30分、1時間、無制限
- アプリ別音量ミキサー: Windows Core Audio を直接使用、追加ドライバー不要
- システム監視: CPU、メモリ、ネットワーク速度、システムドライブの空き容量 / 全容量、バッテリー
- ライブグラフ: CPU、メモリ、ネットワークの直近48サンプルをカード背景に表示
- クリップボード履歴: 初期状態OFF。設定で有効化すると最近のテキストを最大8件、メモリ内だけに保持
- アラーム: OS配色に左右されない独自カレンダーで日時を選択し、指定時刻に同梱MP3をループ再生
- Lumenダイアログ: アラーム停止画面と「はい・いいえ」の削除確認をテーマ対応の独自UIで表示
- 複数メモ: 新規作成したメモをtxtで保存し、5件単位のページ番号で表示
- メモフォルダー: Lumen設定から保存先を直接開く
- クイック設定: ディスプレイ、サウンド、電源の Windows 設定を開く
- 自動起動: Lumen設定内のスイッチでWindowsログイン時の起動をON/OFF
- 専用アイコン: システムトレイと実行ファイルで共通の月形アイコンを使用
- 表示アニメーション: トレイアイコンから開くと下から滑らかに表示
- 外観設定: ダークモードON/OFFとブルー／パープル／ピンク／グリーンの色選択に整理。色アクセントをOFFにすると黒/白だけのシンプルテーマへ変更
- カラーテーマのカスタム色: パレットから好きなテーマ色を選択可能。選択中の色ボタンはハイライト表示
- グラデーション挙動変更: ONでも黒/白ベースを保ちつつ、背景には控えめ、枠線には強めにグラデーションを表示
- グラデーション合成修正: 色アクセントON時はカラーテーマの背景を土台にし、その上に選択中グラデーションを重ねるよう修正
- グラデーション視認性改善: 枠線グラデーションを強め、ON/OFFの違いが分かりやすいように調整
- ライト用グラデーション: 各プリセットを明色へ自動変換し、旧版の暗色設定も移行
- カスタマイズ: グラデーションプリセット、任意のHEXカラー、パレットからの色選択、カスタムプリセット保存/削除、背景の不透明度
- カスタムプリセット表示: 名前が短いプリセットでも既存プリセットと同じ3列幅で表示
- 隠し要素: 設定ボタン10回クリックのカウントは5秒以上空くとリセット
- 背景の不透明度: 設定値0でも背景12%・カード38%を維持
- 大音量保護: ピーク75%以上が2秒続いたアプリを指定音量へ調整（初期状態OFF）
- 自動復元: 75%未満になったら保護前の音量へ復元。単独でも利用可能（初期状態OFF）
- アプリ別音量記憶: アプリが再び音声セッションを開始した時に保存済み音量へ復元（初期状態OFF）
- 設定保存: `%LOCALAPPDATA%\LumenUtility\settings.json` にローカル保存
- 操作補助: `Esc`で設定から戻る／パネルを閉じる、外観設定の初期化
- 新しい音量バー: 塗り分けトラック、発光ノブ、アプリ頭文字バッジ
- アプリアイコン: 音声セッションの実行ファイルからアイコンを表示、取得不能時のみ頭文字へフォールバック
- テーマ対応ツールチップ: 設定・閉じるボタンの白い枠表示を解消

設定とメモはローカルだけに保存し、クラウドへ送信しません。メモは `%LOCALAPPDATA%\LumenUtility\Memos` のtxtファイルです。

## Windows標準機能と重なるため入れない機能

ご指定どおり、次の機能は Windows 版では実装しません。

- Window switcher（Windows の Alt+Tab / タスクビューと重複）
- Window Layout（Windows 11 のスナップレイアウトと重複）

同じ理由で、Finder cut and paste 相当も Windows Explorer の `Ctrl+X` / `Ctrl+V` があるため対象外です。

## まだ移植していない機能

Shelf、アンインストーラー、メディア変換、Cleaning Mode、Quit on close、詳細なプロセス監視は v0.1 には含まれません。macOS API に依存する元コードをそのまま動かすことはできないため、追加する場合は Windows API で個別に再実装します。

## ソースからビルド

Windows 10/11 と .NET 8 SDK 以降が必要です。

```powershell
cd Windows
.\build-windows.ps1
```

または `build-windows.cmd` をダブルクリックします。完成したZIPとインストーラーは `Windows\dist` に作成されます。ランタイム取得が制限される環境では `.\build-windows.ps1 -FrameworkDependent` で軽量版を作成できます。
